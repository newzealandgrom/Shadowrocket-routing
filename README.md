# Shadowrocket-routing
### Цель репозитория
Репозиторий предоставляет **готовые конфигурации и списки правил маршрутизации** для приложения **Shadowrocket** (iOS). 

Shadowrocket — это мощный клиент для прокси и VPN на iPhone/iPad, который позволяет очень гибко управлять трафиком: какие приложения и домены идут через прокси/VPN, какие — напрямую (для скорости), а какие блокируются.

Данный репозиторий особенно ориентирован на **русскоязычных пользователей**. Он помогает:
- Проксировать популярные международные сервисы (YouTube, Google, Telegram, TikTok, Instagram, OpenAI/ChatGPT, Twitter/X, Facebook, GitHub, Apple и др.)
- Направлять российский трафик и банковские сервисы **напрямую** (DIRECT) — это экономит трафик VPN и повышает скорость
- Блокировать нежелательный трафик (реклама, трекеры и т.д.)
- Обходить геоблоки и цензуру выборочно

### Содержимое репозитория

#### Основные файлы в корне:
- **SR_RU.conf** — главная конфигурация, оптимизированная для России (RU). Это полноценный готовый профиль для Shadowrocket.
- **README.md** — минимальное описание репозитория.

#### Папка `lists/` (самая важная часть)
Здесь хранятся готовые списки правил в формате, понятном Shadowrocket. Всего более 20 файлов:

**Сервисные списки:**
- `Apple.list`, `Facebook.list`, `GitHub.list`, `Google.list`, `Instagram.list`, `OpenAI.list`, `Telegram.list`, `TikTok.list`, `Twitter.list`, `YouTube.list`

**Категорийные списки:**
- `proxy.list` — всё, что нужно пускать через прокси
- `direct.list` — трафик, который идёт напрямую
- `reject.list` / `block.list` — блокировка
- `private.list` — приватные/внутренние домены

**Специализированные списки:**
- `domains_banking.list` — банковские домены (обычно DIRECT)
- `domains_geo_detect.list` — сервисы определения геолокации
- `domains_ipchecker.list` — чекеры IP-адресов
- `domains_refilter.list` + `ips_refilter.list` — правила перефильтрации
- `meta_ips.list`, `telegram_ips.list` — IP-адреса Telegram и Meta
- `voice_ports.list` — порты для голосового трафика
- `domains_community.list` — сообщества и социальные платформы

#### Папка `Script/`
- `youtube.response.js` — JavaScript-скрипт для обработки ответов YouTube (часто используется для разблокировки региона, удаления рекламы или изменения поведения плеера).

### Технический анализ конфигурации `SR_RU.conf`

Конфиг построен по стандартной структуре Shadowrocket:

- **[General]** — DNS (Google + Cloudflare + ControlD), отключён IPv6, включён DNS hijacking, настроен bypass для локальных сетей и всех `*.ru` доменов, автообновление конфига с GitHub.
- **[Rule]** — основная логика маршрутизации (очень хорошо продумана):
  1. Сначала блокировка (`reject.list`)
  2. Прямой доступ для приватных сетей, банков, IP-чекеров
  3. Прокси для Discord, Telegram, YouTube, Google, OpenAI, TikTok, Instagram, Twitter, Facebook, GitHub, Apple и многих других
  4. `GEOIP,RU,DIRECT` — весь российский трафик идёт напрямую
  5. `FINAL,PROXY` — всё остальное через прокси
- **[MITM]** — включён (для продвинутых функций перехвата HTTPS)
- Правила подгружаются удалённо через `RULE-SET` с raw-ссылок GitHub — это значит, что при обновлении конфига все списки тоже обновляются автоматически.


## Подробная инструкция по установке и настройке на устройстве (iOS)

### Требования
- iPhone или iPad с iOS 14 или новее
- Установленное приложение **Shadowrocket** (платное, из App Store)
- Хотя бы один рабочий прокси-сервер / подписка (VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и т.д.). Без серверов конфиг работать не будет.

### Шаг 1: Установка Shadowrocket

1. Откройте **App Store**.
2. Найдите приложение **Shadowrocket** (иконка с ракетой, разработчик — Shadowrocket).
3. Установите и откройте приложение.
4. Разрешите создание VPN-конфигурации при запросе.

### Шаг 2: Добавление конфигурации из репозитория (самый удобный способ)

**Рекомендуемый метод — через URL (с поддержкой автообновления):**

1. Скопируйте эту ссылку:
   ```
   https://raw.githubusercontent.com/newzealandgrom/Shadowrocket-routing/master/SR_RU.conf
   ```

2. В приложении Shadowrocket перейдите на вкладку **Config** (внизу).

3. Нажмите кнопку **+** в правом верхнем углу.

4. Выберите **Import from URL** (или "Subscribe" / "Добавить по ссылке").

5. Вставьте скопированную ссылку в поле URL.

6. В поле **Name** введите название, например: `SR_RU_Routing` или `Shadowrocket RU Rules`.

7. Включите тумблер **Auto Update** (Автообновление) — очень важно.

8. Нажмите **Done** / **Сохранить**.

9. После успешного импорта нажмите на созданный конфиг, чтобы сделать его **активным**.

### Шаг 3: Добавление своих прокси-серверов

1. Перейдите на вкладку **Proxy** (или **Servers**).

2. Нажмите **+** и добавьте свои серверы любым удобным способом:
   - Ссылка подписки (рекомендуется)
   - QR-код
   - Ручной ввод параметров

3. После добавления серверов создайте или отредактируйте группу политик:
   - Обычно уже должна появиться группа **PROXY**
   - Настройте в ней ваши серверы (можно использовать режимы: `load-balance`, `fallback`, `select` и т.д.)

4. Убедитесь, что в конфиге для правил используется именно группа **PROXY**.

### Шаг 4: Проверка и запуск

1. На главном экране нажмите большую кнопку подключения (обычно вверху).
2. Дождитесь подключения (статус "Connected").
3. Проверьте работу:
   - Откройте **YouTube** — должен определяться IP вашего прокси-сервера
   - Откройте любой российский сайт (например, yandex.ru или bank.ru) — должен определяться ваш реальный IP
   - Проверьте Telegram — обычно идёт через прокси

**Полезные сайты для проверки:**
- https://whoer.net
- https://2ip.ru
- https://browserleaks.com/ip

### Шаг 5: Дополнительные рекомендации и тонкая настройка

- **Обновление конфига**: Вкладка Config → нажмите на три точки около вашего конфига → **Update** (или используйте автообновление).
- **MITM (перехват HTTPS)**: В конфиге включён. Если не планируете использовать расширенные скрипты — можно отключить в настройках конфига.
- **YouTube**: В конфиге уже есть специальная обработка через `include` и скрипт. Если возникают проблемы с видео — попробуйте переподключиться.
- **Отключение IPv6**: В конфиге уже отключено (рекомендуется).
- **Локальные сети**: Уже добавлены в bypass — домашний Wi-Fi и т.д. не будут идти через VPN.

### Возможные проблемы и решения

| Проблема                        | Решение |
|--------------------------------|--------|
| Нет интернета после подключения | Проверьте, что в группе PROXY есть рабочие серверы |
| Российские сайты тоже через VPN | Убедитесь, что конфиг активен и GEOIP-правило работает |
| YouTube не грузится / медленно | Переподключитесь или обновите конфиг |
| Ошибка импорта конфига         | Проверьте интернет и правильность ссылки raw |
| Хотите только часть правил     | Создайте свой конфиг на основе этого и удалите ненужные RULE-SET |
